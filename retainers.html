Web edit points & ticket tiers

Each website care request is classified as a Light Update or Standard Update. Your retainer includes a monthly edit points budget (for example 4 or 8 points). Each ticket spends points: Light = 1 edit point, Standard = 2 edit points. You can mix tiers within that monthly total, e.g. four Light tickets use all 4 points; two Standard tickets use 4 edit points.

Developmental updates (additional standard page, premium landing/hero under Web Services → Website care) are not counted in edit points. Essential web and Full Digital Essential include 1 developmental update per month; Growth plans include 2 per month. Work beyond Light/Standard tickets may require a custom quotation.
